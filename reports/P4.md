## What P4 delivers

- Surface walking mode (`MovementMode.Surface` / placement **На поверхности**).
- Immutable ground cache with 2D spatial grid, nested/mirrored blocks, SubD/Extrusion/Brep/Mesh.
- Local vertical support window (step up/down), five-probe continuity, slope ≤45°, edge slide, hole stop.
- Eye Z smoothing (τ=40 ms, lag ≤80 mm) for camera only; physical feet stay exact.
- Fly→Surface attach only with local floor; otherwise stay in flight with message.
- Q/E in Surface: no Z change; HUD hint «F — полёт для смены уровня».
- Document geometry/layer/attribute changes invalidate cache and end the active walk.
- Explicit support filter API (`GroundSupportFilter`) for object/layer allow-lists (automatic = all visible).
