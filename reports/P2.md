## What P2 delivers

Placement + live preview + panel (Level/Fly walk from P1; surface *walking* is P4):

- `_AWPanel` — dockable WinForms panel **Наблюдатель**.
- `_AWPlace` — two-step GetPoint: foot → aim; options `Level` / `Surface`, `LookAt3D`.
- Draft states: PlacingFoot → Aiming → Ready; Esc cancels without Undo / repository write.
- Marker conduit: foot ring, silhouette, eye point, yaw arrow, FOV sector (aspect-aware φh).
- Live Shaded preview via owned floating `ARCHWALK_PREVIEW` (P0C path); panel PictureBox.
- Target view resolver: source perspective → last perspective → **Новое окно прогулки** (created only on Enter).
- `_AWEnter` enters from Ready draft; P1 direct GetPoint path remains for Fly / RightButton scripts.
- `_AWP2RunHostTests` — scripted host proofs.

## Live commands after restart

Load `ArchWalk.rhp` **0.3.0** (unload/restart Rhino if an older build is still locked), then:

1. `_AWPanel` → **Поставить наблюдателя** (or `_AWPlace`).
2. Click foot (Level / Surface), aim, confirm → **Войти** / `_AWEnter`.
3. Esc during place cancels draft; Esc during walk keeps view (P1).
4. `_AWP2RunHostTests` repeats the scripted proofs.
