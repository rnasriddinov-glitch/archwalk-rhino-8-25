## What P1 delivers

Thin vertical slice, no panel (P2):

- `AWEnter` — GetPoint for the foot; Level by default; options `Fly` and `RightButton`; capture starts after the command ends.
- `AWExit` — keep the walk camera.
- `AWReturn` — restore the pre-walk snapshot (including two-point).
- `AWResetInput` — emergency release of P0 capture and the P1 session.
- Session states Idle → EnterPending → Captured → Paused / Ending.
- 120 Hz `MotionCore` (Level then Fly), camera applied each UI tick.
- Tab pause, Esc keep-view, Backspace restore, Home, F, Q/E, hitch pause (>250 ms).
- Free-look and right-button look profiles.
- Foreign `BeginCommand` ends the walk and keeps the view. Ctrl+S / Ctrl+Z are pass-through exceptions (session ends, then `_Save` / `_Undo` unless tests suppress scripts).
- Target view destroy, document close, unit change, and app deactivate pause or end the session.

HUD (Russian): mode, speed, H, φv, WASD / Tab / Esc / Backspace.
