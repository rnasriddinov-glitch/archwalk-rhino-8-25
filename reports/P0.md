## Results

### P0A Input — PASSED

- Adapter: thread-local `WH_GETMESSAGE` (not Raw Input, not `KeyboardEvent` as the sole source).
- Physical W is scan `0x11`; `WM_CHAR` `w` and `ц` were eaten (2 key messages, 2 char messages).
- Capture used a temporary floating view; the working camera did not drift.
- Esc / focus-loss release is queued on Idle so the hook is not unhooked from inside its own callback.
- `MouseCallback` cancels clicks while captured.
- Live command: `AWP0Input`. Emergency: `AWResetInput`.

### P0B Camera — PASSED

- `ViewportInfo` snapshot + `SetViewProjection`.
- Parallel and two-point projections restored after a perspective walk apply.
- Eye Z matched 1550 mm in a millimetre document.
- `SetCameraTarget(..., updateCameraLocation: false)` did not slide the camera.
- FOV on three live view sizes (actual `RhinoViewport.Size`, including chrome): error **0.00°** versus `φv` / half of the smaller angle. `CameraAngle` is not full vertical FOV.
- `SetScreenPort` on a copy is not a substitute for a real view size on 8.25.

### P0C Preview — PASSED

- `DisplayPipeline.DrawToBitmap` on a **detached** `new RhinoViewport(source)` returns **null** on 8.25.
- Chosen path: plugin-owned floating native view `ARCHWALK_PREVIEW`, Shaded, then `DrawToBitmap` (180×110). Working view unchanged.
- This is the documented fallback from `03` / `06`, not a static image.

### P0D Data — PASSED (Redo host limit)

- Two observer records in plugin data; Russian name round-trips through `WriteFile` / `OpenHeadless`.
- Isolation: headless records do not appear on the UI document.
- Undo of `AddCustomUndoEvent` works on `CreateHeadless` when wrapped in `BeginUndoRecord` / `EndUndoRecord`.
- `RhinoDoc.Redo()` returned **false** on headless 8.25 after that pattern (same for a scripted UI doc). The undo callback still re-registers `AddCustomUndoEvent` with the swapped tag so command-scoped Redo can work when the host offers it.
- Future-schema flag: unknown major version sets forbid-write instead of wiping records.

### P0E Ground — PASSED

- Extracted **13** world meshes from a plane plus block instances (including a mirrored transform).
- Local downward `Intersection.MeshRay` from a short Z window hit Z = 0 (not a whole-model ray).
- Cache generation increments on invalidate.
- After `AdjustModelUnitSystem(Meters, scale: true)` the hit is still on the floor in metres.
