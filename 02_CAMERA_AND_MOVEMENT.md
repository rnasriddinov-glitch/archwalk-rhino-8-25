# Камера и движение ARCHWALK

Этот документ — единственный источник значений по умолчанию, назначения клавиш и правил расчёта движения. Числа ниже являются решениями продукта для первой реализации, а не характеристиками встроенного WalkAbout или измеренными результатами готового плагина.

## 1 Управление

Таблица действует только при активном захвате прогулки. Событие нажатия для переключателей обрабатывается один раз; автоповтор клавиатуры не переключает режим многократно.

| Ввод | Действие |
| --- | --- |
| W / S | Вперёд / назад |
| A / D | Стрейф влево / вправо без изменения направления взгляда |
| Мышь | Азимут и наклон взгляда вокруг положения глаз |
| Shift удерживать | Временное ускорение ×2 |
| Ctrl удерживать | Точное перемещение ×0,2; чувствительность взгляда ×0,5 |
| Колесо вверх / вниз | Базовая скорость ×1,2 / ÷1,2 за шаг; не изменение объектива |
| Q / E в полёте | Вниз / вверх по мировой Z |
| Q / E по отметке | Опустить / поднять отметку движения; высоту глаз не менять |
| Q / E при следовании полу | Не перемещать; кратко показать «F — полёт для смены уровня» |
| F | Переключить полёт и предыдущий наземный режим по правилам раздела 6 |
| Home | Вернуться к состоянию начала текущей прогулки, обнулить скорость |
| Tab | Пауза и свободный курсор |
| Esc | Выйти, оставив найденный вид |
| Backspace | Выйти и восстановить исходный вид |

Клавиши движения определяются по физическим позициям WASD/QE/F в раскладке US, а не по введённому символу: русские ЦФЫВ не ломают управление. Для иных клавиатур есть переназначение. Стрелки можно назначить дополнительно, но они не обязательны по умолчанию.

Переназначение не отключает Esc и аварийное освобождение ввода. Tab на паузе с фокусом в поле остаётся стандартным переходом между контролами; автоматического возобновления от такого Tab нет.

Ctrl имеет приоритет над Shift. Противоположные направления взаимно сокращаются. W+A не движется в √2 раза быстрее W. В полёте диагональ с вертикальной составляющей также нормализуется. Space и кнопки мыши по умолчанию не выполняют игровых действий; они не передаются Rhino как Repeat/Select, пока ввод захвачен.

Для системных сочетаний Alt+Tab и клавиши Windows сначала освобождается ввод. Для обычных сочетаний Rhino вроде Ctrl+S или Ctrl+Z сессия завершается с сохранением кадра, затем сочетание передаётся Rhino один раз. Это исключения из подавления ввода. Недопустимо одновременно обработать клавишу как действие прогулки и как команду Rhino.

## 2 Профили мыши

### Свободный взгляд по умолчанию

Вход явно захватывает мышь внутри целевого viewport. Курсор скрыт. Горизонтальное вращение не ограничивается краем экрана и допускает любое количество полных оборотов. Камера не орбитирует вокруг объекта и не выбирает под курсором новый центр вращения.

На паузе все перемещения остановлены. Клик в целевом виде или **Продолжить** снова захватывает мышь. Первый клик используется только для возобновления, его отпускание также не должно выделять геометрию.

### Взгляд с правой кнопкой

Это альтернативный профиль, а не дополнительная комбинация внутри первого. Пока целевой viewport активен, WASD управляет движением. Правая кнопка включает скрытый курсор и относительное вращение; отпускание возвращает курсор, но не завершает прогулку. Без удержания правой кнопки мышь не поворачивает камеру.

Выход курсора за пределы целевого окна, клик в панели или другом окне ставит прогулку на паузу. Правая кнопка в прогулке не вызывает контекстное меню и не повторяет команду Rhino. Alt+Tab, Esc, Tab и аварийное освобождение действуют так же, как в основном профиле.

## 4 Единицы и координаты

Все физические настройки хранятся в СИ: метры, секунды, радианы. Координаты опорных точек наблюдателей сохраняются в единицах документа с информацией о масштабе при записи. Rhino получает координаты через единый адаптер единиц.

Для документа, у которого одна единица равна s метрам:

- Высота в единицах документа: H / s.
- Перемещение за время Δt в единицах документа: v × Δt / s.
- Точка глаз E = P + H / s × Z, где P — точка у ног и Z — единичная мировая вертикаль.

| Документ | s | Прибавка к Z для глаз | Перемещение за 1 с при установившейся скорости |
| --- | --- | --- | --- |
| Миллиметры | 0,001 | 1550 | 1300 |
| Метры | 1 | 1,55 | 1,3 |
| Международные футы | 0,3048 | 5,08530184 | 4,26509186 |

Не следует привязывать скорость к размеру bounding box, zoom, размеру пикселя, дальности target или модельному допуску. Прилетевшая из импорта точка за километр не ускоряет человека.

При изменении единиц с масштабированием геометрии точки наблюдателей проходят то же преобразование ровно один раз, физическая высота остаётся 1,55 м. Без масштабирования координаты точек остаются численно прежними, а высота переводится по новому s. В момент изменения единиц сессия завершается, кэш геометрии пересоздаётся. Undo этой операции проверяется отдельно.

Наклонённый CPlane не меняет вертикаль. Нестандартная система координат с другой вертикалью не поддерживается автоматически: модель необходимо привести к мировой Z либо добавить отдельную будущую функцию выбора вертикали.

## 5 Ориентация и проекция

Состояние камеры определяется положением глаз, азимутом ψ, наклоном θ и вертикальным полем зрения φv. При ψ = 0 взгляд направлен по +Y, положительный ψ поворачивает к +X. Положительный θ означает взгляд вверх.

Для описания математики, без привязки к языку реализации:

- Горизонтальное направление h = (sin ψ, cos ψ, 0).
- Направление вправо r = (cos ψ, −sin ψ, 0).
- Полное направление взгляда f = cos θ × h + sin θ × Z.
- Верх камеры u = r × f.
- Служебный target = E + 5 м × f, с переводом расстояния в единицы документа.

f, r и u ортонормированы. Roll отсутствует даже после тысячи поворотов. Камера не использует накопление произвольных матриц вращения, которое может создать дрейф горизонта. Наклон ограничивается до вычисления базиса. Для загрузки некорректных данных предусмотрена валидация.

Дельта мыши умножается на угловую чувствительность, **но не на Δt**. Время нужно скорости перемещения, а не уже измеренному перемещению мыши. Системные события автоповтора клавиш не задают скорость.

При a = ширина / высота целевого кадра:

**φh = 2 × atan(a × tan(φv / 2)).**

При 16:9 и φv = 45° горизонтальный обзор приблизительно 72,73°. В узком или вертикальном окне он другой. Авторитетный параметр — φv; подпись φh вычисляется для текущего окна.

Свойство Rhino CameraAngle означает половину меньшего угла, поэтому φv нельзя напрямую присваивать ему. Адаптер должен построить корректный frustum либо использовать половину min(φv, φh), учитывая пропорции. Подтверждается тестом квадратного, широкого и вертикального окна. См. [CameraAngle](https://mcneel.github.io/rhinocommon-api-docs/api/RhinoCommon/html/P_Rhino_Display_RhinoViewport_CameraAngle.htm).

Предпросмотр использует тот же базис и frustum, с другим размером изображения, но тем же a. В обычной прогулке применяется стандартная перспектива. Восстановление предыдущего параллельного или двухточечного вида возвращает его полную проекцию, а не только координаты камеры.

## 6 Три режима движения

### Ходьба по поверхности

Движение WASD задаётся горизонтальным направлением h и r, независимо от наклона головы. Взгляд в потолок не ведёт человека вверх. Высота опоры определяется локально по поверхности. Система поддерживает пол, пандусы и допустимые ступени.

Это первоначальный режим наблюдателя, поставленного через **На поверхности**, если опора подтверждена также в целевом виде. Если подтверждения нет, вход приостанавливается с предложением явно выбрать **По отметке** или другую опору.

Нет гравитационного падения, прыжка, автоматического приседания, столкновений со стенами или потолком. У края с чрезмерным перепадом движение в опасном направлении останавливается. Смотрение мышью остаётся доступно.

### По отметке

WASD перемещает точку P по горизонтальной плоскости. Значение Z точки P постоянно, пока пользователь не нажимает Q/E или не задаёт другую отметку. Глаза всегда на H выше этой плоскости. Реальный пол может быть ниже или отсутствовать.

Это первоначальный режим установки **По отметке**. Он предназначен для неполной модели, плана или концептуальной стадии. Интерфейс показывает **По отметке Z = …**, не утверждая, что под ногами найден пол. Клавиши Q/E меняют именно отметку, а не пользовательскую настройку роста.

### Полёт

W/S движет вдоль полного взгляда f; A/D — вдоль r; E/Q — вверх/вниз по мировой Z. Сумма направлений нормализуется с учётом их фактического угла, затем применяется выбранная скорость. При компенсации противоположных векторов движение нулевое. Крен отсутствует.

В полёте P — условная точка на H ниже глаз. Это сохраняет единую модель данных, но не означает контакт с полом. HUD показывает **Полёт**.

F сохраняет предыдущий наземный режим. Возврат из полёта в **По отметке** фиксирует текущую условную отметку P и не скачет к старому этажу. Возврат к **Ходьбе** разрешён только при локально подтверждённой опоре в диапазоне от Pz − максимальной ступени вниз до Pz + максимальной ступени вверх. Иначе полёт остаётся включён и появляется «Рядом нет пола — поставьте наблюдателя на поверхность».

Смена любого режима обнуляет скорость. При успешном присоединении к полу допускается только явно ограниченная коррекция на найденную локальную опору. Перенос на несколько метров выполняется отдельным действием установки с предпросмотром.

## 7 Время и ощущение движения

Движение отделено от отрисовки. Состояние клавиш хранится как набор нажатых направлений; симуляция использует монотонные часы. Не использовать календарное время, частоту key-repeat и количество событий MouseMove как время.

Расчёт выполняется фиксированными шагами 1/120 с. Между расчётными состояниями допустима интерполяция позиции для кадра; она не меняет траекторию. Направление взгляда обновляется перед ближайшим кадром и по умолчанию не проходит через дополнительную задержку.

Скорость плавно приближается к целевой через экспоненциальный отклик с коэффициентом **1 − exp(−Δt / τ)**. При разгоне используется τ разгона, при отпускании или уменьшении целевой скорости — τ торможения. Разворот вводится через новый вектор цели, без импульса. τ = 0 означает немедленное применение. Порог для окончательного обнуления — 0,001 м/с.

При отпускании W на 1,3 м/с тормозной путь по этой модели около 32,5 мм. Это намеренное короткое торможение. При τ = 0 остановка мгновенна. Во время точного движения остаточное смещение соответственно меньше.

При паузе, потере фокуса, Home, выходе, ошибке, изменении единиц или режима скорость обнуляется немедленно, без плавного торможения. Удерживаемые до паузы клавиши требуют отпускания и нового нажатия после возобновления.

За одно обновление обрабатывать не более 12 фиксированных шагов, то есть не более 100 мс движения. Если интервал 100–250 мс, лишнее время не догонять. Если разрыв превышает 250 мс, включить паузу, сбросить накопленные дельты и клавиши; продолжение только явно. Это защищает от рывка после блокировки UI. На стабильно медленной сцене предложить более лёгкий режим отображения; не обещать полную скорость при зависающем Rhino.

Покачивание головы, автоматическая смена FOV при ускорении, крен на поворотах и кинематографическое запаздывание выключены конструктивно. Они мешают оценивать архитектуру и точно выбирать кадр.

## 8 Опора и лестницы

### Поиск опоры

Пол определяется по геометрии, а не по названиям слоёв «Floor». Автоматический набор включает поддержанную видимую геометрию целевого вида, в том числе locked. Пользователь может вместо него выбрать конкретные объекты или слои для опоры; это удобно, если мебель мешает распознаванию. Списки хранятся в настройках документа, исходные объекты не меняются.

Численный допуск опоры ε равен физическому абсолютному допуску документа, ограниченному снизу 0,5 мм и сверху 5 мм. Он применяется к совпадению привязки с поверхностью и границам локальных проверок; не используется как скорость или размер человека. Геометрический снимок должен обеспечивать погрешность поверхности порядка 2 мм в рабочей области опор. Если существующая render mesh слишком груба, строится отдельная сетка; увеличение ε не заменяет исправление сетки. Параметры тесселяции и время подготовки измеряются в P0E.

Пять проб: центр и четыре точки вокруг него в радиусе 100 мм. Для движения нужна центральная опора и минимум две дополнительные допустимые пробы. Вспомогательные пробы могут попадать на соседнюю проступь: сравнивается допустимость перепада, а не обязательное равенство их Z. На лестничных границах основную высоту задаёт центральная проба, а не среднее по пяти точкам.

Искать следует в локальном вертикальном интервале от предыдущей точки ног: максимум ступени вверх плюс численная погрешность до максимума ступени вниз плюс погрешность. Не пускать луч сверху всей модели. Учитывать допустимый уклон и близость к предыдущей опоре. Нормали сетки могут быть перевёрнуты; геометрический тест опоры должен устойчиво работать на двусторонних поверхностях и проверяться на открытых плоскостях. Сама по себе ориентация треугольников не доказывает, что это потолок или пол.

Нельзя ограничиться единственным непроверенным результатом nearest-hit: нужен кандидат, прошедший диапазон высоты, доступность поверхности и проверку непрерывности. Если кандидатов несколько, сначала сохранять прежнюю связную опору, затем выбирать минимальную допустимую коррекцию высоты. Не прыгать на перекрытие выше только из-за порядка перечисления объектов.

Нулевая толщина пола допустима. Отверстие в полу реально разрывает опору. Дублирующиеся копланарные поверхности не должны вызывать дрожание. Самопересечения, повреждённые тела и мебель нельзя надёжно классифицировать одним raycast; для них предназначены явный набор опор и режим по отметке.

### Препятствия и края

Подъём ≤220 мм принимается как ступень, спуск ≤300 мм — как допустимый перепад. Большая высота или отсутствие центральной опоры запрещает соответствующее горизонтальное перемещение. При касательном движении вдоль края разрешённая компонента сохраняется, если её опора подтверждена. При невозможности надёжно выделить такую компоненту допустима полная остановка этого шага.

Непрерывность проверяется вдоль пройденного сегмента, а не только в конечной точке: пространственные пробы не реже 50 мм при ускоренном ходе. При исчерпании бюджета расчёта остановить сомнительное движение; не перескакивать непроверенный участок.

Движение сквозь стену разрешено, если с другой стороны продолжается допустимый пол. Закрытая дверь не блокирует путь в v1. Низкий потолок также не является физическим препятствием: это честное ограничение камеры без тела, а не проверка проходимости здания.

### Плавность высоты

Физическая точка ног сразу следует принятой опоре. Для отрисовки глаз применяется отдельное короткое сглаживание Z с максимальной погрешностью 80 мм относительно Pz + H. На плоском полу погрешности нет. После остановки на ступени отклонение должно стать менее 2 мм за 250 мс. Этот эффект можно отключить для строгой проверки высоты.

Ограничитель предотвращает чрезмерное запаздывание глаз на частой лестнице. Он не используется для расчёта следующего пола: опора всегда отсчитывается от физической точки ног. Иначе ошибки накопятся и приведут к потере этажа.

## 9 Геометрическая видимость

Скрытый объект или скрытый родительский слой не является опорой. Видимый locked-объект является. Учитываются видимость экземпляра и вложенные трансформации блоков. Геометрия, отсечённая активными поддержанными clipping planes целевого вида, не даёт невидимую опору.

Clipping plane не является стеной. Созданная отображением заливка сечения не становится настоящим полом. Если точную селективную видимость конкретного procedural-объекта или clipping-конфигурации нельзя воспроизвести в 8.25, она отмечается неподдержанной для автоматической опоры; пользователь явно выбирает движение по отметке. Изображать полноценную физику поверх несогласованных данных нельзя.

После редактирования пола, видимости или блока сессия останавливается либо завершается согласно документу 03. Устаревший кэш не используется для следующего шага. Изменение модели не должно тихо телепортировать наблюдателя.

## 10 Камера возле поверхности и выход

Near/far frustum и настоящие clipping planes модели — разные механизмы. Не назначать слепо чрезвычайно маленький near на всей сцене: это может ухудшить глубину изображения. Первоначально используется родной механизм Rhino, а отсутствие нежелательных срезов на тестовых интерьерных дистанциях проверяется в техническом прототипе. Если требуется корректировка near/far, она локальна виду, сохраняет достаточную точность глубины и полностью обратима.

Служебный target в 5 м служит для согласованности камеры при ходьбе. Он не привязан к направляющей точке установки и не удерживается на старом объекте. При выходе с сохранением кадра можно установить удобный центр дальнейшего orbit: ближайшая видимая поверхность по центру кадра, если расстояние 0,5–100 м; иначе оставить 5 м. Это не меняет положение глаз, направление или FOV. Адаптер проверяет, что API не сдвигает камеру при смене target.

При возврате к исходному виду восстанавливается оригинальный target, без пересчёта. На любом пути выхода видимые геометрия, CPlane, пользовательские настройки навигации и выделение не должны меняться вследствие очистки плагина.
