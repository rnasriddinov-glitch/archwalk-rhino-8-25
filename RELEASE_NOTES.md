# ARCHWALK 1.0.0

Проверено: Rhino **8.25.25328.11001**, Windows x64, .NET **8.0.25**.

## Состав v1

- Установка наблюдателя в два клика с живым превью и панелью.
- FPS-прогулка: Level / Surface / Fly, физический масштаб, безопасный захват ввода.
- Сохранение наблюдателей в 3dm, Undo/Redo, Named Views.
- Следование полу: локальное окно ступеней, уклон, край отверстия, вложенные блоки.
- Локальный пакет Yak для Windows (`packaging/dist`).

## Известные границы v1

- Нет столкновений со стенами.
- Basic clipping planes не фильтруют опору автоматически (A40): при активном clipping используйте режим «По отметке» или явный набор опоры.
- Горячая выгрузка .NET-плагина без перезапуска Rhino не обещается.
- Публикация в общий каталог Package Manager — отдельное действие владельца.

## Обновление

GUID и schemaVersion стабильны. Установите новый `.yak` поверх прежней версии и перезапустите Rhino.
